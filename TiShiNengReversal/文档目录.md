# 文档目录

本项目是对"体适能"校园体育打卡 APP（`com.bxkj.student`，博星科技）的静态逆向分析工作区。以下是项目中所有 `.py` 脚本和 `.txt` 文件的用途说明。

---

## Python 脚本

### 根目录

| 文件 | 功能 | 依赖 |
|------|------|------|
| `axml_decode.py` | 解析 Android 二进制 XML（AXML）格式，提取字符串池和属性值 | struct（标准库） |
| `probe_dex_structure.py` | 探测 360 加固 classes.dex 的结构布局，定位合法 DEX 终点后的夹带数据区，通过魔数扫描和熵分析判定加密/压缩边界 | struct, math, collections（标准库） |
| `probe_blob_cipher.py` | 对 classes.dex 夹带 blob 头部进行单字节 XOR/加法/滚动密钥暴力探测，尝试还原 DEX 魔数或可读内容 | struct, collections（标准库） |
| `decode_jiagu_meta.py` | 使用频率分析得到的 XOR 密钥 0xC6 解码 360 加固元数据区，提取类名/Activity/包名等索引信息 | struct, collections, re（标准库） |
| `so_recon.py` | 对 ELF SO 文件做静态侦察，提取动态符号（导入/导出）并扫描与加密、网络、反调试相关的敏感字符串 | pyelftools |
| `key_hunt.py` | 在 ARM64 SO 中定位硬编码常量字符串的地址，通过反汇编扫描 .text 中所有 adrp+add 引用点来判断其是密钥值还是普通标签 | pyelftools, capstone |
| `global_xref.py` | 对 ARM64 SO 中指定全局变量地址做交叉引用分析，判定段归属、读磁盘初值，并扫描 .text 中所有引用点以追踪密钥初始化位置 | pyelftools, capstone |
| `disasm_so.py` | ARM64 SO 函数级反汇编工具，解析 ADRP/ADD 引用还原只读数据（硬编码密钥/盐），并通过 BL 目标符号识别推断加密算法 | pyelftools, capstone |
| `replace_law_refs.py` | 将 Markdown 文档中的法规简码（L1~L10）批量替换为对应的中文法规全称 | re（标准库） |
| `md_to_docx.py` | 将 Markdown 文件转换为带格式（字体、代码块语法高亮、表格）的 Word (.docx) 文档 | python-docx |

### tsn\ 子目录（assets 资源分析专用）

| 文件 | 功能 | 依赖 |
|------|------|------|
| `tsn\scan_assets.py` | 遍历 APK assets 目录，通过魔数识别文件类型并计算香农熵，分类和识别加密/压缩资源 | 标准库 |
| `tsn\analyze_czl.py` | 对 `assets/na.czl` 做 hexdump 并暴力尝试 256 种单字节 XOR 解密，寻找含关键词（http/amap/key）的明文 | 标准库 |
| `tsn\czl_records.py` | 解析 na.czl 中以 `\x00\x01\x01\x00` 为头标记的记录结构，逐条暴力 XOR 解密并输出最佳可读文本 | 标准库 |
| `tsn\czl_keyfirst.py` | 以"记录首字节即为 XOR 密钥"的假设解析 na.czl 各条记录，验证该密钥方案能否还原 UTF-8 明文 | 标准库 |
| `tsn\wbsafe_strings.py` | 从 `assets/libwbsafeedit` 二进制中提取可读字符串，筛选与 JNI 符号、加密、网络 URL 相关的敏感信息 | 标准库 |

### dsh-vm\ 子目录（第7轮动态脱壳 / unidbg 环境）

> 一句话结构：`dsh-vm/` 存放动态脱壳全链路——`base.apk`（原包 132MB）、`sdk/`（cmdline-tools / platform-tools / emulator / system-images）、`avd-home/`（AVD 配置）、`maven/`（Maven 3.9.9 + maven-repo，unidbg 依赖）、`pyvenv16/`（★frida 16.7.19 可用环境）、`frida/`（脱壳脚本 + frida-server + classes.txt）、`dumps/`（14 个内存 dump dex + `jadx_out/` 反编译源码 cap_4/cap_8）、`tools/`（jadx-1.5.1）、`logs/`。

| 文件 | 功能 | 依赖 |
|------|------|------|
| `dsh-vm\frida\dump_dex.py` | ★无 hook 纯内存扫描 dump 真业务 dex（绕过 360 反 hook），native libc write 落盘到设备 files/dexcap/ | frida 16.7.19（pyvenv16） |

### recon_*（SO 库快速侦察画像）

对目标 .so 做架构/符号/字符串概览，用于选择后续深入反汇编的函数。

| 文件 | 目标 SO | 描述 |
|------|---------|------|
| `recon_tsnsecret.txt` | libtsnsecret.so | 内嵌 OpenSSL/BoringSSL，6809 个导出符号；业务加解密/认证核心 |
| `recon_devInfo.txt` | libdevInfo.so | 贝子广告 SDK 设备信息采集（getBootMark/getUpdateMark） |
| `recon_commonV2.txt` | libcommonV2DevInfo.so | Adscope 通用设备标识 SDK |
| `recon_emucheck.txt` | libemulator_check.so | 模拟器检测库（detect/sigaction/shellcode） |
| `recon_umeng.txt` | libumeng-spy.so | 友盟设备指纹库（getNativeID/getNativeTag/xpCy） |
| `recon_timonitor.txt` | libti-monitor.so | 快手 JVMTI 调试监控库（enableJdwp/Agent_OnAttach） |
| `recon_liantian.txt` | libliantian.so | 连天防篡改/DRM 验证库（check_vendor/vendor_decode） |
| `recon_sgcore.txt` | libsgcore.so | 快手签名核心库（getMagic/getClock，仅 4 个导出） |

## 工作流概览

```
APK 解包
  ├─ axml_decode.py          → manifest_decoded.xml / axml_err.txt
  ├─ probe_dex_structure.py  → 定位加固 blob 边界
  ├─ probe_blob_cipher.py    → 暴力尝试解密 blob
  ├─ decode_jiagu_meta.py    → 提取加固元数据（类名索引）
  │
  ├─ so_recon.py             → recon_*.txt（各 SO 画像）
  ├─ key_hunt.py             → 定位硬编码常量地址
  ├─ global_xref.py          → 交叉引用追踪密钥初始化
  ├─ disasm_so.py            → dis_*.txt（关键函数反汇编）
  │
  ├─ tsn\scan_assets.py      → tsn\assets_scan.txt
  ├─ tsn\analyze_czl.py      → na.czl XOR 爆破
  ├─ tsn\czl_records.py      → na.czl 记录解析
  ├─ tsn\czl_keyfirst.py     → na.czl 密钥验证
  └─ tsn\wbsafe_strings.py   → tsn\wbsafe_allstrings.txt

报告整理
  ├─ replace_law_refs.py     → 法规简码替换为全称
  └─ md_to_docx.py           → Markdown → Word 导出
```
